# 온라인 저장소 연결 (구글 시트 + Apps Script)

내 사이트(https://saisoo.github.io/re_space/)에서 공동 편집·온라인 저장·의견을 쓰기 위한 준비입니다. 처음 한 번만 하면 됩니다.

1. [sheets.new](https://sheets.new)로 새 구글 시트를 만들고, 이름을 `덕영 공간 배치 저장소`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(⚙️) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 허용합니다. "확인되지 않은 앱" 화면이 나오면 **고급 → (안전하지 않은) 이동**을 누릅니다.
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 `index.html`의 `SHEET_DB_URL`에 넣습니다.

저장된 내용은 시트의 `data` 탭에 쌓입니다. 시트를 지우거나 다른 사람과 편집 권한을 공유하지 않도록 주의하세요.
